# Ricardo Design - Portafolio Web Premium

## 🚀 Descripción
Portafolio profesional de servicios web con diseño Liquid Glass, scroll visual y animaciones modernas.

## 🎨 Características
- **Glassmorphism:** Efecto de vidrio esmerilado en toda la página
- **Scroll Visual:** Animaciones parallax, reveal y stacking al desplazarse
- **Responsive:** Diseño adaptable móvil/tablet/desktop
- **Performance:** Optimizado para velocidad y SEO
- **Premium:** Paleta lujo (Negro + Oro) con tipografía elegante

## 🛠 Tecnologías
- HTML5 semántico
- CSS3 con animaciones y backdrop-filter
- JavaScript vanilla (sin dependencias)
- Google Fonts (Playfair Display + Inter)
